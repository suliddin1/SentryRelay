## Reporting a Vulnerability

Security is a core focus for SentryRelay, which handles webhook authentication, signature verification, and delivery dispatching.

If you discover a security vulnerability in SentryRelay, please do **not** open a public issue. Instead, report it responsibly:

1. Send an email to [suliddin677@gmail.com](mailto:suliddin677@gmail.com) with the subject `[SECURITY] SentryRelay Vulnerability Report`.
2. Include a detailed description of the vulnerability, reproduction steps, proof-of-concept (if available), and potential impact.
3. Reports will be reviewed promptly and remediated prior to public disclosure.

Thank you for helping keep SentryRelay secure.
